# Now-Playing Overlay

Pulls information about the currently playing song from a media player (title, artist, album art), and displays that on-stream as an overlay using an OBS browser source.

**WARNING:** This is currently just a PROTOTYPE, and will be rewritten later as a plugin for [Streaming Toolbox](https://github.com/theodoros1234/streaming-toolbox). DO NOT USE for anything important.

Currently only supports Linux. Windows support should be added in the future.
